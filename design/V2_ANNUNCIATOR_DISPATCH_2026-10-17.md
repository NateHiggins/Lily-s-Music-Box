## Changes and authority

The native board gains seven physical dispatch keys serving the actual
passenger lift's B1 and six residential stops. Its original eighth indicator
is retained as an unused dash. The old isolated eight-floor Otis game is not
the building's lift authority and cannot introduce a roof stop here.

Click takes a Bakelite key, mouse motion pushes its four-millimetre stroke,
and the next click releases it. A spring returns it. Partial travel makes no
contact. A full stroke calls the existing passenger-car request API only when
the board's actual flag, contact alignment and reset establish continuity.
The lift retains doors, busy refusal and landing interlocks. Holding a key
does not repeatedly request a trip. The indicator follows actual cabin height.
No private score, rider simulation, job award or automatic repair is added.

The native Blender assembly contains nine mapped partitions and 78 closed
stocks: pierced apron, ceramic guides and spring seats, metal stems, caps,
five-turn springs, contact bus, screw terminals and jacketed leads. Spring
shape keys change coil pitch while retaining wire thickness and the fixed
lower bearing. Insulating seats keep return springs off the common bus;
only the stem tip reaches it at full stroke. Native checks cover 21 travel
samples, seven displaced-shaft negative controls and both spring states.
Existing board owners and live indicator materials remain in place.

Version-two mechanism snapshots include strokes and consumed-contact state.
Geometry exists before household restoration; the real lift binds later in
production startup. Old service snapshots remain accepted and initialize
released keys. Restore never dispatches a journey. Invalid boolean versions
are explicitly rejected before numeric comparison.

The common mouse controller accepts an optional positive finite motion gain;
all existing grips retain one. New keys use 0.025 for useful partial travel.
The actual-input driver applies the same gain. No explanatory player UI is
introduced. Registered custom PBR materials, authored metre UVs, loaded maps
and mip filtering remain required. A measured precision-import override fixes
compressed UV/normal failures; generated LODs remain enabled.
