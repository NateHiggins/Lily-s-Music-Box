## Branch and authority integration

Followups now match the entire normalized reply. A phrase inside a fresh physical
command cannot hijack it. Leave always wins. A new unrelated topic closes the
old branch; a later “yes” cannot revive it. Original named forks still work.
Physical action requests execute no action. Nothing changes WorkOrders,
MaintenanceInventory, ResidentConversations, resident trust, cases or quests.

The existing explicit event entry point accepts seven finite event families:
hesitation, exploration, revisit, paper_jam, typing_interrupted, typing_resumed
and story_discovery. Individual lines are marked in the existing bounded
seen dictionary and exhaustion returns no reply. Snapshot/restore retains it.
No new save field or random chatter is introduced.

Event producers MUST witness the circumstance and arbitrate delivery before
calling: powered printer available, no protected conversation, no pause/focus
conflict. The event call consumes its line immediately; it is not a cancellable
print queue. Do not call it while merely considering a future event.
Story discoveries must originate in an existing story authority, never an idle
timer, location guess or a request parser. These producers are not wired here.

## Campaign calendar and papers

**companion_calendar_context.gd** enriches a detached context from the existing
CampaignClock, current WeatherManager source/conditions and an optional active
paper selection. **respond_calendar** is the integrated conversation entry point.
The caller supplies the paper/date only from the active reading surface; querying
the catalogue alone does not establish that the player read it.

Weather only uses the campaign-calendar source within its authored year:
10 November 1928–9 November 1929. Explicit live/simulation overrides suppress
calendar commentary rather than contradicting the real presentation.
Current reports and as-of issued forecasts retain distinct labels, issue time,
validity and correction. The helper never reads the host clock, calls a network
or creates a second weather simulation. Observed snow/storm/rain/fog/heat/cold
outranks the season. Twelve monthly comments cover the remaining fair intervals.

NewspaperCatalog.published_now gates the selected paper before issue lookup.
Morning/evening publication remains 06:00/17:00 campaign E.S.T. The response
prints masthead, issue date, headline and deck verbatim, followed by a bounded
authored opinion about the lead. Topic matching respects word boundaries.
Older papers retain their own date and get historical framing. Future/unpublished
pages and absent active selections produce no invented report. The adapter never
collects a paper, grants knowledge or reads tomorrow's article for a callback.
All 365 days can use current published leads; this is topic-responsive commentary,
not a claim of 730 individually authored edition reviews.

Calendar comments use approved prefixed line IDs and appear once per bounded
memory, while factual reports remain available on repeat requests. No persistent
familiarity across actual campaign reloads is claimed before save integration.
