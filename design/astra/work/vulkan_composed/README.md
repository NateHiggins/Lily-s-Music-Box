## Wrappers and gates

run_case.py is read-only to game, isolates APPDATA, retains exact native
stdout/stderr/exit, hashes source/assets and both installed engine binaries,
and uses the unchanged 180-second serial runner. variant_case.py owns exact
source transforms only during an explicitly assigned lane and restores
candidate bytes in finally.

gate.py reports the two native signatures separately. Only the previously
identified exact host loader-manifest errors are classified as inherited.
Unknown errors, retention, missing captures/receipt, incomplete retirement,
source/engine drift and renderer fallback remain failures. Engine zero alone
never passes. The strict unpair-only expected-red predicate is unchanged.

pair_bookkeeping.py and pair_bookkeeping_case.py provide a separate
source-supported paired-bookkeeping contract: exact helper-only omission,
current viewport guard, two exact headers at bound source sites, complete
selected-scope checks/captures/retirement, actual engine zero, no unrelated
errors/retention, unchanged other inputs, then exact restored clean candidate.
An access violation or incomplete broader scope is invalid. Required artifact
map entries and hashes are verified before classification. Current pure
parser/source/restoration/artifact controls total 57 passing tests; these are
metadata controls, not render evidence.
