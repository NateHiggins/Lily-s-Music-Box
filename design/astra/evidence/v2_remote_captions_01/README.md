# V2 acoustic caption presentation — pending engine verification

Base 2cf0ae5. V2 now mounts a remote caption display that listens to the
existing acoustic reality-event signal. It delegates thresholds, stable
sampling, 48-caption cap, words and appearance to the existing manifestation
implementation. Only uniquely resolved FunctionalProp subjects are admitted;
labels become children of the actual subject at a local .72 m vertical offset.
No legacy graph coordinate survives as the final display position.

The display does not emit acoustic arrivals, advance the case or record wake
residue. It rejects arrivals while unseen, stabilized or resolved, clears old
labels when recurrence changes, deduplicates repeated arrivals and removes its
external child labels when exiting. V1's display is unchanged. Unmounted
subjects deliberately remain undisplayed; this is not completion of V2's
acoustic topology or all building props.

Eight scoped scripts, including the pending wake test and its driver chain,
pass gdtoolkit syntax parsing. This parser was installed outside the project
in a temporary tooling directory and adds no game dependency. It does not
replace Godot type checking, runtime tests or visual inspection.
