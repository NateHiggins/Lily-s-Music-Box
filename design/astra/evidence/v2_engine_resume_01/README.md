# V2 engine resumption and upper-apartment baseline

Owner re-authorized Godot after the source-only construction period. This packet
resumes actual Forward+ checks on `e36fbcb` plus the scoped repairs recorded here.
It is not a V2 completion, selector-cutover, or human acceptance receipt.

## Repairs

- Domestic door hinge selection now has an explicit boolean type. Godot rejected
  inference from the dictionary value, preventing V2 startup.
- Bathroom detail support transforms validate numeric zero values instead of
  type-sensitive array equality. All eighteen JSON records previously failed.
  Integer and JSON-float zeros are accepted; nonzero yaw/offsets and numeric
  strings remain rejected alongside the existing malformed-source controls.
- Household save validation checks version/kind types before comparing values.
  A boolean version previously triggered a script error. Unsupported, nonfinite,
  string and malformed records are rejected without partially restoring props.
- Kitchen panel reconstruction now resets the complete local transform and
  flushes that change while physics synchronization is disabled, then restores
  synchronization. Previously a saved open panel retained an old world-space
  physics pose. Normal opening/closing still uses the existing physics tween.
- Prepared tests now compile under the project's warning policy. Disk equality
  compares the complete expected JSON representation, including JSON's floating
  numeric version. Cabinet tests verify the newly added durable control behavior.
  Category counts include the eighteen upper wall intervals and Mae's coffee
  table. The timber census is four actual source material surfaces. Wall probes
  find their one collision shape by type rather than an autogenerated node name.
