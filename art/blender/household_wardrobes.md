# Native household wardrobes and completion repair bench

Evidence class: **INERT**

**build_household_wardrobes.py** creates thirteen source-content variants for
21 existing wardrobe actors. The source plan retains the thirteen V1 records,
eight completion copies, four garment colours/hems per source, case dimensions
and original 92-degree hinges. Its exact source/template guards reject drift
before grouping. The native file contains 884 connected closed stocks, 143
material/component partitions and 447,616 unique triangles.

Cases use eased timber, fitted rail sockets, frame-and-panel leaves and brass
hinges. Applied circular rebates clear fixed hinge necks and pins. Cloth uses
closed thin folded skins, wire hangers and rail hooks; cool/green cloth includes
a paired-leg hem. Existing fine linen maps avoid upholstery-scale weave. The
warm colour is a local linear tint. No new texture, lettering or catalogue key
is introduced. Reference photographs are not baked into any asset.

The original private wardrobe actor, broad box collider, two pivots, audio,
service card and tween remain the authority. The V2 subclass calls its original
ready method, then replaces only primitive visual children. Fixed and moving
meshes share immutable resources per native variant, in a world-owned cache.
Moving mesh transforms are rebased against the original hinge transform.

**inspect_household_wardrobes.py** verifies connected manifold stock, real joins,
metre UVs, corner-normal orientation, local bearings and continuous angular
extrema. **inspect_household_wardrobes_context.py** checks all 42 leaf sweeps
against room wall faces and neighboring furniture using conservative continuous
bounds. Three completion bedrooms exposed an original projecting-knob/wall
crossing. Shallow native brass buttons retain the knob axes and clear it without
altering anchors or opening angles. All 84 wardrobe floor contacts pass.

The same context inspector checks the basement repair bench's four floor
contacts and neighboring furniture. This actor uses its exact **3B_workbench**
template from the already-reviewed **work_tables.blend**. The runtime helper
checks kind, bounds and surfaces before accepting that copy. Existing native
geometry and material bytes are reused; its original identity and placement
remain. Its broad hull is replaced by the same exact native collision as the
template.

Run the builder, local inspector, context inspector and renderer with
**run_fabrication_batch.py**. Review both closed finishes and all thirteen open
contents before the one warm Godot import. The shared module
**household_wardrobes** checks all actors, mesh sharing, original collision,
hinges, ordinary open/close interaction, service cards and retirement. It also
checks the completion bench's source-equivalent geometry and floor bearings.
The normal shared run includes the nine prior domestic/desktop modules.

Capture selection uses **ORISON_FABRICATION_ACTORS** without narrowing geometry
validation. Camera station selection prioritizes front views and can use 90 or
100 degree inspection FOV in compact bedrooms; the original 72 degree camera
setting is restored. No production camera behavior changes. Two initial views
failed framing; the targeted correction passes. The 3B open view still partly
hides its contents behind the near leaf. Its native contents are reviewed; a
front content view remains queued with the next planned room pass.

Evidence lives in **art/renders/orison_v2/household_wardrobes_20261007**. This is
scoped geometry/visual QA, not a runtime contract. Warm room lighting, coarse
surrounding finishes, remaining props/appliances/lights/cords and the existing
seven-texture shutdown warning remain open. Whole V2 is incomplete.
