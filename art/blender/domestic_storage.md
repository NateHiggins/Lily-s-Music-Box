# Native household storage and preparation cabinets

Evidence class: **INERT**. Build guide and scoped geometry/visual QA.

The **domestic_storage** library serves 43 existing actors: eleven shelves,
seventeen sink supports/counters and fifteen wall cupboards. Eight variants
retain seven original V1 records, 26 existing V2 interpretations and ten
completion copies. The separate **prep_cabinets** library serves all twelve
existing sliding preparation mechanisms. These twelve are existing V2 designs.

Storage has 421 closed stocks, 25 partitions and 79,344 unique triangles.
Preparation cabinets have 38 stocks, eight partitions and 7,096 triangles.
Both builders compare source geometry, material assignments and bounds before
sharing variants; every original actor retains its identity and placement.

Shelves retain five board datums, all 43 original books on the occupied variant,
and the source container envelopes. Rounded uprights and welded bearing rungs
support the boards; books have covers, spines and inset paper blocks. Containers
have thin walls and lids. The low planshelf retains its two close upper boards.
The 4B sink counter preserves its opening and 905mm top. Other sink frames use
folded legs and closed thin rails within the source envelopes.

Wall cupboards are hollow cases with a shelf, framed passive leaves and
recessed grips. Seven installations need 10mm rear mounting battens; eight
are flush. Native checks resolve the actual wall owner, including the C
kitchens whose neighbouring bathrooms own the supporting partition. All
sixty wall samples meet retained planes outside source apertures.

Preparation cabinets retain the 900mm worktop, original panel poses and
382mm slide. Fitted top/bottom tracks carry the leaves. The fixed source handle
crossed the moving leaf's path; a recessed brass finger cup at the same X/height
centre clears it. A thin centre underlap closes the original sightline gap.
Conservative swept stock bounds prove clearance throughout the complete slide.
The original script, all nine collision boxes per cabinet, animation, prompts,
household save owner and care/maintenance owner remain unchanged. The native
factory replaces only visual children under the body and its SlidingPanel.

Run the family builders, local inspectors and context inspectors with
**run_fabrication_batch.py**. Native context checks 160 floor bearings, sixty
wall bearings, eleven retained passive-stock contacts, four radio contacts and
forty toaster-foot contacts. One shelf/radio pair has intentional coplanar
bearing triangles, explicitly checked for zero penetration. Native tests cover
closed connected stocks, metric UVs, normal/tangent orientation, joins and
the engine's absolute UV edge budget. Render every changed state before import.

The shared Godot batch selects **domestic_storage**, **prep_cabinets**, and the
seven previous furniture/desktop/nook/lamp modules. One world passes 6,880 module
checks plus 24 batch checks. Both original cabinet interactions are exercised
for every actor, including saved state and retirement. Ten native views and
twelve final room views are reviewed. The capture follow-ups change no assets.

Standing-view selection now checks full framing and visibility rays for storage,
including attached stock and the separate supported radio. Candidate angles
advance by fifteen degrees. **ORISON_FABRICATION_ACTORS** can select one known
representative actor for a corrective capture, while the module still validates
every installed actor. Results retain the actual capture feet. Use it only
with the applicable family; an unknown representative fails validation.

Existing catalogue maps provide all finishes; no bitmap or global lighting
policy changes. Linear native tints receive the existing explicit sRGB encoding
at runtime. Whole-room lighting and broad material balance remain unfinished.
The complete nine-module run retains the seven-texture shutdown warning; the
final single-capture run has empty stderr, which does not resolve that warning.
