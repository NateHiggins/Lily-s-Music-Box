Native radiator candidate kit. Uninstalled; no runtime acceptance.

The build requires Python with NumPy/Pillow, Blender5.2, and an ordinary clone
of the repository containing its accepted catalogue and heating native stock.
It does not read any former prototype directories. Use explicit --root,
--out and --blender arguments; outputs must be disposable, never game/art.
All construction stages share one Blender process. --reuse verifies all
recipe, imported source, texture and artifact hashes before skipping work.
No test receipt is repinned or described as a new run on a cache hit.

Final candidates: packed_union_candidate.blend, pitch_shims_candidate.blend,
automatic_vent_finished_candidate.blend, sliding_wall_ties_candidate.blend,
and their four scratch GLBs. The16woodshimstocks are exported separately.
mount_plan.json owns the46surveyed support placements and five rod lengths.
The packed library excludes obsolete unlined sockets, flat old union nuts,
and the old packing placeholder. Native intermediate blends remain build
inputs. Graphited packing is still an UNREGISTERED material prototype.

The exported cloth has Spread_01..Spread_20 shading anchors. Runtime must
interpolate the two adjacent anchors for a desired spread; their positional
path is exactly the original native Seated->SpreadForRemoval path. Using
a single distant target directly defeats the qualified shading frames.
The independent final-buffer checker samples180adjacent-frame states.

Native room clearance and service motion were reviewed separately against
actual acquired world geometry. This package does not replace composed
Godot captures, actual player-control/disk-reconstruction tests, live mipmap
proof, navigation, performance, or human visual/listening acceptance.
