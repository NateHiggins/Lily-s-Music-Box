# PHONE-A — ordinary line mechanism

Bounded Forward+ mechanism proof for `HouseSwitchboardProp`. These are not
production-placement claims; PHONE-B owns the measured lobby placement and the
existing opening-report seam.

Sequence:

- `00_idle_control_a/b`: frozen idle controls, byte-identical; whole-frame RMSE
  `0.000000`.
- `01_asking`: one endpoint asks and the upper answering lamp falls bright;
  against idle RMSE `0.0160153`.
- `02_answered`: A's listening key is thrown; RMSE `0.0107138`.
- `03_carrying`: the key remains thrown and one cloth cord hangs in a U between
  the board and trunk; RMSE `0.0145755`.
- `04_released`: physical line returned to idle. Whole-frame difference from
  the session-opening control is `0.0029573`; this is not claimed as zero.
- `05_unanswered`: an asking appearance expires and the apparatus returns to
  the same visible idle state as release. PHONE-A emits one neutral unanswered
  fact but owns no paper receipt; message custody is a later phase.

The first sheet was rejected because the bounded camera photographed the
mahogany back of the case, making every state falsely identical. The second
sheet exposed the working face. Its first cord was also rejected as a nearly
black shallow arc on the shelf; the accepted cord has high plugs, a low bight,
cloth color and enough separation to read as a carried circuit.

No caption is needed to distinguish idle, asking, answered and carrying. The
labels remain immediately literal (`HOUSE LINE`, `A`, `B`, `TRUNK`); House
English is taught in prompts and semantic rendering, never substituted for
safety or operating labels.
