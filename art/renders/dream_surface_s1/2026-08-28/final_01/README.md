# DREAM-SURFACE-S1E Forward+ evidence

This directory is the immutable `final_01` renderer evidence set captured from
the reconstructed S1E branch.  The fold-crab sheets use the production
`DreamCritterController` batch and the lifecycle sheet uses the production
`DreamMossColonyRenderer`, fauna director, cellular packets, and residue path.

## Completed sheets

- `fold_crab/anatomy`: ten fixed-purpose anatomy views.
- `fold_crab/gait`: seven gait/support views without changing gait authority.
- `fold_crab/examination`: deploy, contact, palpate, information acquisition,
  withdrawal, and return/deposit sequence.
- `fold_crab/fold`: fixed-camera unfolded/folded comparison.
- `lifecycle`: pioneer through authorized cleanup, including cilia tending,
  reporting, disturbance, recall, senescence, residue, and stain.
- `advanced_fauna`: partial renderer output from the existing production fauna
  style harness.  This sheet is retained as diagnostic evidence, not claimed as
  a complete phenotype acceptance matrix, because the isolated checkout lacks
  several non-versioned imported texture/font artifacts.

Each directory contains a generated `contact_sheet.png`.  Exact capture facts,
test verdicts, performance readings, and limitations are in
`capture_receipt.json`.  Automated capture completion is not human aesthetic
acceptance.
