# DREAM-COLOR-C1 checkpoint

C1 established an approved governing color concept but failed human visual acceptance.
The packet is preserved unchanged as the baseline for C1B.

Observed visual failures:

- tissue reads as opaque beige/olive clay;
- process colors read as painted stripes;
- metamerism globally tints the render;
- crystal response reads as cyan transparent plastic;
- senescence changes value without destroying optical organization;
- furnished filament light collapses the organism into an orange lump.

C1B does not supersede this checkpoint or the unresolved S2J checkpoint.
