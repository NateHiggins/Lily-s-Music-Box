# Dream fauna FA2 — harmless trophic loop production proof

FA2 extends the existing presentation-only `DreamFaunaDirector`; it does not
create a second ecosystem owner. Wine Anemones, Ribbonettes and the one Loupe
join Gilder's Buttons and Tessellates as five shadowless MultiMesh batches.
The fixed 3 Hz owner still carries only four bounded room densities, forgets
rooms with the Atlas, owns no collision/light/hazard/save record, and never
changes topology or pursuit.

Wine Anemones are joint-bound dark-live tufts fed by low exposure and
detritus. Ribbonettes are paired bead helices that appear with grazer surplus.
The Loupe is an animal-scale low quadruped with one circular lens-face; it
consumes only a bounded density term and cannot contact or damage the player.
The Tenant reabsorbs all three FA2 families below their real birth-frame.
