# Neighbour return facades v1

`day/04_roof_skyline.png` is the accepted clear-day production roof control.
The visible side and rear planes of the authored neighbour envelopes now carry
the same physical 1.45 m bay / 2.70 m storey rhythm as their primary facades.
Dark and occupied windows are calculated from the same opening, so illumination
cannot drift away from its aperture. The change stays inside the existing
`PersistentNeighbourMasses` multimesh and adds no draw, node, light, collision,
shadow, interior, or persistence owner.

Three distant-infill arrangements were rendered and rejected before this
control. One sat on the wrong side of the camera, one intersected the authored
far-south building, and one was occluded at its base and photographed as
floating upper storeys. None is retained in source or evidence.

The broad charcoal band below the horizon remains. The rejected trials prove it
is a nearer occluding geometry owner rather than empty sky. This checkpoint
does not disguise that separate defect by stacking counterfeit buildings over
it; it fixes only the measured return elevations it can own honestly.
