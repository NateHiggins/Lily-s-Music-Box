# Retained grade source map

Evidence class: **INERT**

**retained_grade_source.json** is a geometry-authoring input for the bounded
Orison ground builder. It preserves the inspected original owners and the
distinction between exact source solids, occupied volumes and qualified native
clearances. Source bindings stop stale regeneration; reconcile changed owners
before replacing this map. It is not runtime data or acceptance evidence.

The complete construction method, native sources, ordered rebuild, test fixture
provenance and open boundaries are described in **art/blender/groundworks.md**.
