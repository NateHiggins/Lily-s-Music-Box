# Mina's debug infestation

Debug Building automatically populates Mina's V2 apartment with all sixteen
accepted Blender critter species, the hero tentacle, active margin palps,
surface tendrils, moss and living encroachment. The existing production owners
run movement, contact, lamp receptors, signals and global attention. Births
are explicitly staged for testing, not evidence of natural population growth.

Open **F1 → GO — teleports → Mina infestation — visit**. The adjoining
**Reset infestation** and **Clear infestation** buttons rebuild the debug
population or restore the original room materials. Reset restores all species
after they move or expire. F1 and backtick retain their existing pointer rules.
The pause menu still provides access to debug controls and the zoo.

Walk around, aim the service lamp, and operate fixtures: real player world
modification signals reach the shared ecology director. Critters are seeded on
ray-tested apartment surfaces; the infestation adds no movement colliders.
Clear it to compare ordinary maintenance against the infested room.

This is session-only debug staging. Ordinary New Game and Continue do not seed
it; it writes no case, affection, money or infestation save records. Existing
maintenance still has its usual saved effects when the player performs it.
The separate zoo remains available. Designed placeholder species and maze-only
pursuers/hazards are not fabricated into living apartment creatures.
