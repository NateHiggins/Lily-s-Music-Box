# Orison clear-sky plates v1

Generated with the built-in OpenAI image-generation workflow on 2026-08-25,
then resized with Lanczos filtering to the production 4096 × 2048 half-dome
contract. These are atmosphere/luminance foundations, not astronomical maps.
Sun, moon and twelve catalog stars are positioned by `CelestialEphemeris`.

- `orison_clear_milky_way_half_dome_4k.png`: accepted second pass after the
  first was rejected for an obvious horizontal seam. Prompt requested neutral
  long-exposure astrophotography, continuous Milky Way dust lanes, no clouds,
  horizon, bodies, constellation art, text or conspicuous navigational stars.
- `orison_clear_day_half_dome_4k.png`: seamless clear New York daylight
  atmosphere, no clouds and no baked solar source.
- `orison_clear_twilight_half_dome_4k.png`: dawn/evening clear atmosphere with
  uniform warm horizon and no baked source.

The dynamic cloud layer owns every cloud pixel in production. Therefore zero
cloud cover is genuinely cloudless rather than a painted storm with its rain
particles disabled.
