NASA SVS describes this as the 2019 natural-color, Hapke-normalized LROC WAC
mosaic, assembled from Lunar Reconnaissance Orbiter camera data and centered
on 0 degrees longitude. Missing polar coverage was filled with lower-resolution
LRO laser-altimeter albedo. It is supplied for rendering use; scientific work
should use the underlying archived products.
